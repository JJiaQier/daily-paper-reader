## 摘要
轨道环境中的自主自由飞行机器人需要既通用又资源高效的控制器，然而为每个任务剖面维护单独的任务特定策略在架构上脆弱，并且随着需求演变限制了操作灵活性。我们提出了HYPER-GNC，一个多任务强化学习框架，其中超网络将物理信息任务嵌入映射到共享演员-评论家策略的权重，使单个紧凑控制器能够掌握四个不同的GNC任务：速度跟踪、对接、检查以及带避障的导航。连续嵌入空间允许控制器在部署时泛化到新的任务配置，无需任何重新训练。大量实验表明，HYPER-GNC在显著的惯性扰动和外部机体力扭矩下保持稳定性的同时，实现了与单任务专家相当的样本效率。我们还在物理卫星模拟器上进一步验证了该框架，成功弥合了所有任务剖面的仿真到现实差距。代码、训练模型和部署脚本均已公开，以支持可复现性。

## Abstract
Autonomous free-flying robots in orbital environments require controllers that are both versatile and resource-efficient, yet maintaining a separate, task-specific policy for each mission profile is architecturally brittle and limits operational flexibility as requirements evolve. We introduce HYPER-GNC, a multi-task reinforcement learning framework in which a hypernetwork maps physics-informed task embeddings to the weights of a shared actor-critic policy, enabling a single compact controller to master four distinct GNC tasks: velocity tracking, docking, inspection, and navigation with obstacle avoidance. The continuous embedding space allows the controller to generalize to novel mission configurations at deployment time without any retraining. Extensive experiments demonstrate that HYPER-GNC achieves sample efficiency comparable to single-task specialists while maintaining stability under significant inertial perturbations and external body wrenches. We further validate the framework on a physical satellite emulator, successfully bridging the simulation-to-reality gap across all mission profiles. Code, trained models, and deployment scripts are made publicly available to support reproducibility.

## 2. 论文提出的方法论

### 核心思想
- **HYPER-GNC 框架**：利用**超网络（Hypernetwork）**将物理信息任务嵌入映射为共享 Actor-Critic 策略的权重，使单个紧凑控制器掌握四个不同 GNC 任务，并在连续嵌入空间中通过“语义插值”实现新任务的零样本（zero-shot）组合，无需任何在线重训练。

### 语义任务嵌入（Physics-Informed Embedding）
- 任务上下文向量定义为 5 维连续向量：`ek = [αpos, αatt, αvel, αbrake, αsafe]`，对应经典 GNC 任务分解中的控制优先级（位置误差、姿态误差、速度保持、负加速度/制动、避障行为）。
- 训练时每维在给定范围内均匀采样，充当参数空间数据增强与正则化，防止策略过拟合到离散任务 ID。
- 部署时嵌入可由操作员、任务规划器或按任务阶段硬编码设定，无需在线学习。
- 通过嵌入插值可以合成训练中未见的行为组合（如 Safe Docking with Obstacles = αbrake=1 且 αsafe=1）。

### 架构细节
- **主网络（Main Network）**：Actor 与 Critic 为分离网络但结构相同，均由自适应线性层构成；Actor 输出两个头参数化 Beta 分布（通过形状参数 α、β 输出动作）。观测向量经过拼接与零填充后输入网络。
- **超网络（Hypernetwork）**：每个自适应层挂载一个超网络，输入语义嵌入，经共享 MLP（语义编码器）后送入四个调制头：
  - 权重缩放头（Weight Scaling）
  - 权重加性头（Weight Additive）
  - 偏置缩放头（Bias Scaling）
  - 偏置加性头（Bias Additive）
- **Rank-1 向量分解**：调制矩阵通过预测 Key 向量 k∈R^din 与 Query 向量 q∈R^dout 的外积生成，计算方式为 `Ψ(ek) = q(ek) × k(ek) / √dout`。相比全秩调制头，每层参数量从 4,096 降至 64（16 倍缩减），类似 LoRA 的低秩思想，适合星载硬件内存限制。
- **参数调制公式**：
  - 动态权重：`Wdyn(ek) = Wbase × (1 + ΨW_scale(ek)) + ΨW_add(ek)`
  - 动态偏置：`bdyn(ek) = bbase × (1 + Ψb_scale(ek)) + Ψb_add(ek)`
- **稳定初始化**：Key/Query 头权重以近零方差（σ=10⁻⁴）初始化，缩放头输出偏移 +1.0，使初始状态接近恒等调制（Ψscale→1, Ψadd→0），避免训练初期破坏基础网络。类似 ResNet 的残差初始化与 FiLM 条件化思想。

### 训练与任务设定
- 使用 **PPO（Proximal Policy Optimization）** 端到端训练全部组件。
- 在 Isaac Lab 仿真器中为 Int-Ball2 建模，4,096 个并行环境（每个任务 1,024 个）同时训练四个策略。
- 四个任务及其奖励函数：
  1. **速度跟踪（Track Velocities）**：匹配 6-DOF 目标线速度与角速度，奖励为线性/角速度误差项之和。
  2. **对接（Docking）**：接近目标位置并对齐航向，奖励包含位姿误差、速度调节、边界惩罚与进程奖励。
  3. **检测（Inspection）**：依序通过预设目标位姿序列，奖励额外包含到达目标的序列奖励。
  4. **避障导航（Navigation with Obstacles）**：到达目标位置并避免碰撞，奖励包含位置误差、速度项、边界项与碰撞惩罚。
- **领域随机化（Domain Randomization）**：扰动质心（CoM）位置、总质量变化、外部机体力/力矩大小，以增强 sim-to-real 迁移鲁棒性。
- **Sim-to-real 细节**：Int-Ball2 使用连续动作空间 + Beta 分布；Floating Platform（5kg 圆柱形气浮平台）使用二值推进器动作空间，因此策略输出切换为 Gaussian 分布，避免 Beta 分布在边界处梯度不稳定问题。

- 论文通过在二维嵌入平面（固定其他维度）上可视化策略的激活行为，验证了嵌入插值的语义可解释性。

### 消融研究（Table V & VI）
- **调制模式消融**：依次移除权重加性（Add）、权重缩放（Scale）或仅保留偏置调制，结果均显著劣化（例如仅偏置调制时 Docking 成功率骤降至 12%）。去除缩放分量后，任务性能下降 5%～20%，表明权重缩放与加性调制对任务适应同样重要。
- **Rank-1 分解与外积结构消融**：将 Rank-1 换成完整矩阵或更高秩（如 Rank-4），参数量成倍增加但性能无显著提升；Rank-1 在保持足够表达力的同时最优地控制了内存开销。
- **语义嵌入 vs 离散任务 ID**：使用 one-hot 任务 ID 输入超网络时，在插值任务（如 Docking with Obstacles）上表现极差（<10%），而语义嵌入可以外推到未见的嵌入值，说明“物理信息”的连续嵌入是零样本组合的关键。
- **初始化策略消融**：若将 Key/Query 初始化为零（而非近零小值），训练失真或崩溃；采用近零初始化 + 缩放头偏移 +1 的策略可稳定收敛。

5. **完整的仿真到真实硬件验证**：在 Int-Ball2 仿真与真实气浮平台上均取得高成功率，证明了工程可行性。

## 7. 讨论：局限性、潜在改进与开放问题

- **对语义嵌入的依赖**：任务嵌入 α 的维度与范围由人工定义，若未来出现未涵盖的行为（如非刚体操作、多人协作），需要重新设计语义空间。
- **超网络的推理开销**：虽然参数量小，但每次推理需同步计算超网络输出与动态权重；计算量仍高于固定策略，未来可考虑低秩权重离线缓存或低精度量化。
- **任务间冲突缓解机制简单**：超网络只能隐式缓解梯度冲突，未显式建模任务关系；未来可引入任务共性与差异的显式分解（如 Task Arithmetic / 子空间识别）。
- **训练稳定性的敏感因子**：Key/Query 初始化方差、缩放头偏移等超参数对性能影响较大，需更自动化的初始化方案。
- **未与其他先进 MTRL 算法（如 Soft Modularization、Gradient Vaccine）对比**：对比基线集中在经典方法，拓展基线可更全面评估位置。
- **真实实验场景受限**：仅在二维气浮平台验证，未覆盖 3D 微重力下的六自由度动态；后续可在抛物线飞行或轨道演示中进一步验证。

## 8. 结论

HYPER-GNC 通过超网络将语义任务嵌入映射为共享策略的权重调制，成功在单个紧凑控制器内掌握多个 GNC 任务，并支持任意任务嵌入的组合与插值。其性能在训练任务上不输单任务专家，在组合任务上大幅超越现有基线，且训练成本低于重训多个专家。该方法为空间机器人提供了“可即时组合、内存友好、无需在线重训”的统一控制范式，为未来太空任务中的自主性提升带来了切实可行的新路径。

## 摘要
移动操纵需要生成整身动作块，这些动作块需同时满足目标到达、碰撞避免、基座运动学约束、机械臂关节限位以及轨迹平滑性。基于流的生成策略为从专家演示中学习多模态且时间上一致的运动先验提供了一种高效范式，但仅靠模仿训练无法在演示分布之外提升策略质量。我们提出RLMM-Flow，一种结合专家流策略预训练与潜空间强化学习后训练的基于流的移动操纵框架。该框架首先学习一个从专家演示中捕获多模态整身运动先验的流策略。随后冻结预训练的流策略，并由一个潜空间转向网络将其初始噪声导向更高价值的动作块。为稳定高维潜空间优化，我们在联合训练潜空间评论家与潜空间演员之前，先预热一个动作空间评论家，并引入从粗到细的潜空间转向，逐步将控制从共享视界的潜表示扩展到全维残差表示。在移动操纵运动规划基准上的实验表明，RLMM-Flow在任务成功率、碰撞避免和轨迹质量上显著优于纯模仿流策略和现有的强化学习后训练基线，同时保持了基于流的快速推理。

## Abstract
Mobile manipulation requires generating whole-body action chunks that jointly satisfy goal reaching, collision avoidance, base kinematic constraints, manipulator joint limits, and trajectory smoothness. Flow-based generative policies provide an efficient paradigm for learning multimodal and temporally consistent motion priors from expert demonstrations, but imitation-only training cannot improve policy quality beyond the demonstration distribution. We propose RLMM-Flow, a flow-based mobile manipulation framework that combines expert flow-policy pretraining with latent-space reinforcement learning post-training. The framework first learns a flow policy that captures a multimodal whole-body motion prior from expert demonstrations. The pretrained flow policy is then frozen, while a latent steering network steers its initial noise toward higher-value action chunks. To stabilize high-dimensional latent optimization, we warm up an action-space critic before jointly training the latent critic and latent actor, and introduce coarse-to-fine latent steering that progressively expands control from a horizon-shared latent representation to a full-dimensional residual representation. Experiments on mobile manipulation motion-planning benchmarks show that RLMM-Flow substantially improves task success, collision avoidance, and trajectory quality over imitation-only flow policies and existing reinforcement learning post-training baselines, while preserving fast flow-based inference.

- 生成式策略（尤其基于流匹配的方法）可以从专家演示中学习多模态运动先验，但**纯模仿学习受限于演示数据分布**，无法生成超出示范质量的轨迹
- 直接对多步生成式策略（流/扩散模型）应用强化学习存在诸多困难：似然评估、策略比率估计、信用分配和通过完整传输过程的反向传播均不直接

**论文主张：** 通过"专家流策略预训练 + 潜空间强化学习后训练"的两阶段框架，在保持快速推理的同时，突破模仿学习的性能上限。

## 2. 方法论

### 总体框架（两阶段）
1. **第一阶段——流策略预训练**：从高质量专家演示中学习整身运动先验
2. **第二阶段——潜空间强化学习后训练**：冻结预训练策略，优化潜空间转向网络，引导初始噪声向高价值轨迹靠拢

### 网络架构（四大组件）
| 组件 | 功能 |
|------|------|
| **流策略 π_dp** | Transformer条件流架构，由点云、机器人状态、流时间嵌入共同条件化，生成整身动作块 |
| **潜空间转向网络 π_W** | 级联Transformer，先预测基座相关潜变量，再条件化预测机械臂相关潜变量 |
| **动作评论家 Q_A** | 在动作空间评估解码后的整身动作块 |
| **潜评论家 Q_W** | 在潜空间估计噪声潜变量的价值，为潜空间优化提供引导 |

### 输入表示
- 点云包含三部分：**机器人本体点**（前向运动学生成）、**目标点**（期望末端位姿）、**场景点**（周围环境）
- 每点含3D坐标 + 1维类型特征，由Point Transformer编码
- 与当前机器人状态、任务目标和流时间嵌入融合，形成共享场景表示

### 关键技术创新

**① 级联潜空间转向（Cascaded Latent Steering）**
- 基座运动负责全局导航，机械臂运动负责局部操纵，两者角色不同
- 转向网络先预测基座相关潜变量，再在其条件下预测机械臂相关潜变量，显式建模全局→局部依赖关系

**② 动作评论家预热（Action-Critic Warm-up）**
- 问题：DSRL-NA联合更新Q_A、Q_W和π_W导致耦合的移动目标问题——Q_W的蒸馏目标随不准确的Q_A持续变化，π_W更新又改变Q_A评估的动作分布
- 方案：先专一更新Q_A（N_pre步），期间潜变量从固定标准高斯先验采样，之后再激活Q_W和π_W的训练，为潜空间优化提供稳定的蒸馏目标

**③ 粗到细潜空间转向（Coarse-to-Fine Latent Steering）**
- 问题：直接优化完整H×d_w高维潜变量搜索难度大，容易产生时间不一致的修正
- **粗阶段**：对潜变量沿时间维做平均池化→得到d_w维共享向量→按时间复制回H×d_w形状。有效搜索维度从H·d_w降为d_w，学习全局运动趋势和基座-机械臂整体协调
- **细阶段**（t≥t_cf）：引入时间相关残差 w_res = w_raw − w_coarse，以 λ_res 比例叠加，恢复时间维独立调节能力，精细化局部避障、末端精度、关节运动和轨迹平滑性

### 离线强化学习算法细节
- 奖励函数：五项归一化加权和——目标到达 r_goal、基座运动学约束 r_lim、碰撞 r_colli、平滑性 r_smooth、关节限位 r_joint
  - 权重：α₁ = α₅ = 2.5, α₂ = 2.0, α₃ = α₄ = 1.5
- 混合质量数据：7,500高质量 + 1,500结构化次优轨迹（5:1混合），拓宽价值覆盖，缓解评论家过估计
- 潜评论家训练使用混合采样 q_t = ρN(0,I) + (1−ρ)sg[π_W]（ρ = 0.5）
- 动作评论家通过固定目标网络 + Polyak平均更新（τ = 0.005）

### 流策略预训练细节

## 6. 主要结论与发现

1. **潜空间强化学习后训练优于动作空间后训练**：DSRL-NA和RLMM-Flow系列均优于动作空间AWR和IQL，说明在高维整身动作空间中直接优化会偏离预训练流策略学到的连贯运动流形
2. **QA预热和粗到细转向各自有效且互补**：
   - QA预热提供了更稳定的价值蒸馏目标，改善约束满足
   - 粗到细转向降低早期潜空间探索难度，对碰撞避免尤其有效
   - 两者结合达到最佳性能
3. **Base Flow优于M2Diffuser（无优化）**：logit-normal调度的流策略比扩散策略学习更高效、推理更快；测试时优化虽能改善M2Diffuser，但大幅增加延迟（3.89s vs 0.21s）
4. **混合质量数据扩大价值覆盖**：缓解了对专家流形外动作的乐观估计问题
5. **真实世界验证了仿真结论**：零样本迁移取得一致趋势，最强方法达到32%成功率、9%碰撞率

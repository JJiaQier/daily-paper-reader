## 摘要
图像目标导航是具身机器人领域的一个关键挑战，要求智能体仅凭目标图像到达指定目标。现有的强化学习方法将感知观察直接映射到动作，但难以建模长时依赖，常导致次优轨迹。为解决此局限，我们提出RoamFlow，一种生成式导航框架，利用MeanFlow预测轨迹合成的平均速度场，实现高效少步生成并降低推理延迟。我们进一步采用两阶段训练策略，结合专家模仿以稳定初始化与强化学习以任务特定策略微调。在Habitat仿真和真实机器人平台上的大量实验表明，RoamFlow在实时约束下实现了高效推理，同时保持强大的导航性能。

## Abstract
Image-goal navigation is a key challenge in embodied robotics, where an agent must reach a target specified solely by a goal image. While existing reinforcement learning approaches map perceptual observations directly to actions, they struggle to model long-horizon dependencies, often leading to suboptimal trajectories. To address this limitation, we propose RoamFlow, a generative navigation framework that leverages MeanFlow to predict the average velocity field for trajectory synthesis, enabling efficient few-step generation and reducing inference latency. We further adopt a two-stage training strategy that combines expert imitation for stable initialization with reinforcement learning for task-specific policy refinement. Extensive experiments in both Habitat simulation and real-world robotic platforms demonstrate that RoamFlow achieves efficient inference while maintaining strong navigation performance under real-time constraints.

## 1. 核心问题与研究动机
- **任务背景**：图像目标导航（Image-Goal Navigation）要求机器人仅凭一张目标图像到达指定位置，是具身机器人领域的基础挑战。
- **现有局限**：
  - 传统强化学习方法将感知直接映射到单步动作，难以捕获长时序依赖，导致轨迹短视、次优。
  - 生成式策略（扩散模型、流匹配）虽能生成连贯轨迹，但推理需要多步迭代，计算延迟高，难以满足实时部署需求。
  - 蒸馏方法虽加速但牺牲了轨迹质量与多样性。
  - 大部分生成策略仅依赖模仿学习，无法适应未见环境或纠正专家次优行为。

## 2. 方法论：RoamFlow 框架

### 核心思想
- 利用 **MeanFlow** 模型预测**平均速度场**（interval-level displacement），将高斯噪声一步或少步转化为任务轨迹，大幅减少推理步数。
- 采用**两阶段训练**：第一阶段通过专家模仿学习（IL）稳定初始化；第二阶段通过强化学习（RL）用任务奖励微调策略，提升目标导向与避障性能。
- 同时引入轻量级**轨迹评估器**（Trajectory Evaluator），在多候选轨迹中选择安全、平滑、朝目标前进的轨迹执行。

### 关键技术细节
- **架构**：将当前RGB-D观测与目标图像编码后通过Transformer融合为隐变量，条件化控制MeanFlow生成器（UNet）预测平均速度场。
- **MeanFlow 公式**：定义平均速度 \( u(x_t, r, t) = \frac{1}{t-r} \int_r^t v(x_\tau, \tau) d\tau \)，通过最小化 \( \|u_\theta - u\|^2 \) 训练网络，实现少步传输。
- **随机化处理**：为了支持RL，在确定性MeanFlow上加入学习性噪声网络，将传输过程转化为高斯马尔可夫链，从而可计算轨迹对数似然。
- **RL优化**：使用PPO，奖励函数包括成功奖励、滑步惩罚、进度奖励、碰撞惩罚。轨迹级优势估计后优化策略。
- **轨迹评估器**：监督信号来自距离场，融合安全性和平滑性得分，训练回归模型，推理时选择得分最高轨迹。

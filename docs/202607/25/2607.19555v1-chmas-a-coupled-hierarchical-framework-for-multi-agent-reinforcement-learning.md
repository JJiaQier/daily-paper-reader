## 摘要
多智能体强化学习系统在平衡全局协调与局部执行方面面临基本挑战，且涉及不同的时间尺度。本文介绍了耦合分层多智能体系统（CHMAS），这是一种新颖的框架，它将多智能体决策分解为集中式战略规划和分布式战术执行，并具有双向信息流。战略层集成所有智能体的状态以及一个独占的全局环境状态，每T个时间步生成引导动作；而战术智能体执行由策略引导和局部邻域观测增强的分布式策略。与现有单向控制的分层方法不同，CHMAS建立了一种反馈机制，其中累积的战术奖励通过耦合系数λ影响战略目标，确保战略计划基于战术可行性。为了解决分层学习中的非平稳性问题，我们提出了一种异步更新协议，其中战略参数每N_f个战术回合更新一次，允许战术策略在战略变化之间收敛到准平稳点。我们提出了一个捕捉完整系统动态的一般双层公式和一个可处理的加性近似，以实现严格分析。理论分析证明，在标准假设下，该异步方案在K次战略更新后，战略层实现了O(log K/√K)的收敛速度。在多智能体觅食领域的实验验证表明，尽管存在分层耦合，但成功学习了空间分割的探索策略，且两层均稳定收敛。

## Abstract
Multi-agent reinforcement learning (MARL) systems face fundamental   challenges in balancing global coordination with local execution   across different temporal scales. This paper introduces the Coupled   Hierarchical Multi-Agent System (CHMAS), a novel framework that   decomposes multi-agent decision-making into centralized strategic   planning and distributed tactical execution with bidirectional   information flow. The strategic layer integrates all agents' states   with an exclusive global environmental state to generate guidance   actions every $T$ timesteps, while tactical agents execute   distributed policies augmented by strategic guidance and local   neighborhood observations. Unlike existing hierarchical approaches   with unidirectional control, CHMAS establishes a feedback mechanism   where accumulated tactical rewards influence strategic objectives   through a coupling coefficient $λ$, ensuring strategic plans   remain grounded in tactical feasibility. To address the   non-stationarity inherent in hierarchical learning, we propose an   asynchronous update protocol where strategic parameters update every   $N_f$ tactical episodes, allowing tactical policies to converge to   quasi-stationary points between strategic changes. We present both a   general bi-level formulation capturing full system dynamics and a   tractable additive approximation enabling rigorous analysis.   Theoretical analysis proves that this asynchronous scheme achieves   $\mathcal{O}(\log K/\sqrt{K})$ convergence for the strategic layer   after $K$ strategic updates under standard assumptions. Experimental   validation in a multi-agent foraging domain demonstrates successful   learning of spatially partitioned exploration strategies, with both   layers converging stably despite hierarchical coupling.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：多智能体强化学习（MARL）在现实场景（如机器人编队、交通管理、资源分配）中面临全局协调与局部执行间的跨时间尺度协调挑战。纯集中式方法因联合状态空间随智能体数量指数增长而不可行，纯分布式方法虽可扩展但牺牲了长期协调质量。现有分层MARL方法（如Feudal Networks、Option-Critic）多为**单向控制**（高层策略直接指挥低层），缺乏从战术层到战略层的反馈，导致战略计划可能脱离战术可行性。此外，分层学习存在**非平稳性**：战略变化改变战术层感知的环境，而战术演化又影响战略所依赖的执行特性。
- **整体含义**：提出一种**双向耦合**的分层框架CHMAS，通过集中式战略规划（每T步）与分布式战术执行（每步）的双向信息流，并引入异步更新协议缓解非平稳性，实现多智能体系统在**多时间尺度**上的协调。理论证明战略层收敛速率为O(log K/√K)，并在觅食任务中验证了稳定学习。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 将多智能体决策分解为两个层次：
  - **战略层**（高层）：每T个时间步生成一次全局指导动作（如区域中心），访问**独占的全局环境状态**（如细胞覆盖图）和所有智能体状态，进行集中式规划。
  - **战术层**（低层）：每个智能体基于局部观测（自身状态、邻居状态）和战略指导，每步执行分布式策略。
- **双向耦合**：
  - **向下耦合**：战略指导通过观测增强、奖励调制和持久时间影响战术行为。
  - **向上耦合**：累积的战术奖励通过**耦合系数λ**（0到1）影响战略奖励函数，使得战略优化考虑战术可行性。
- **异步更新协议**：战略参数每Nf个战术回合更新一次（采用递减步长η_str = α/√k），战术参数更新更快，从而允许战术策略在战略变化之间收敛到准平稳点，将非平稳问题转化为交替的平稳子问题。

### 关键技术细节
- **战略MDP**：状态 S_str = S_env × ∏_{i=1}^N S_i，动作 A_str = ∏_{i=1}^N A_str_i（每个智能体的个性化指导），奖励 R_str = R_global + λ Σ_t Σ_i r_tac_i,t。
- **战术MAMDP**：每个智能体 i 的观测 o_tac_i,t = φ_i(s_i,t, {s_j,t}_{j∈N_i}, a_str_i,k)，联合转移概率因式分解于通信图，奖励 r_tac_i,t 依赖于局部状态、邻居动作和战略指导。
- **算法：异步分层策略梯度（AHPG）**：
  1. 每Nf个回合开始，战略层观测全局状态，采样并广播指导动作。
  2. 每个战术回合内，在给定固定指导下，所有智能体并行执行T步，收集经验，更新战术策略（使用分布式策略梯度或DQN）。
  3. 每Nf个回合结束，战略层计算累积战术奖励 R_tac_k，获得战略奖励 r_str_k = R_global(env, a_str_k) + λ R_tac_k，更新战略参数（步长 α/√k）。
- **收敛性保证**：在标准假设（平滑性、PL条件、稀疏梯度偏差）下，设 η_str_k = α/√k，η_tac = β/√K，Nf = c√K，战略层梯度范数期望的min界为 O(log K/√K)，战术层平均梯度范数为 O(1/√K)。（证明基于两时间尺度随机近似和PL条件下的SGD分析）

## 3. 实验设计

- **环境**：自定义 25×25 GridWorld，4个智能体执行**合作觅食**。全局环境状态 s_env ∈ {0,1}^625 记录细胞访问情况（覆盖探测）。战略层可访问完整状态，战术层仅看到局部观测（位置、附近资源、战略指导）。
- **智能体**：每个智能体被分配一个 9×9 区域（由战略指导决定中心），离散动作 {移动、采集、等待}。
- **奖励结构**：
  - 战术层：r_tac_i,t = 收集奖励 − 0.01 − 0.01·[超出区域]。
  - 战略层：R_global_k = 0.01 × 新访问细胞数；R_str_k = R_global_k + λ Σ r_tac_i,t，λ = 0.5。
- **实现细节**：战术层采用**多智能体DQN（MA-DQN）**（参数共享、决斗架构、Double Q-learning、优先经验回放）；战略层采用**集中式DQN**。训练400回合，5个独立种子。
- **对比方法**：论文**未提供与其他现有方法的定量对比**，仅展示CHMAS自身的学习曲线（Q值、回报、损失）。没有对比QMIX、MADDPG或单向分层方法。实验更多是作为**概念验证**，而非严格的SOTA比较。

- CHMAS成功学**空间分割的探索策略**：战略层学会分配不重叠的9×9区域给每个智能体，战术层在区域内高效收集资源并遵守边界约束。

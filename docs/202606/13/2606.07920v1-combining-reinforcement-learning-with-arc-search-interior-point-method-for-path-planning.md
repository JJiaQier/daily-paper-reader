## 摘要
包含障碍物的环境中的路径规划具有众多实际应用。该问题因其固有的非线性和非凸性而具有挑战性。因此，发展出了多种技术来解决这一问题，其中机器学习和最优控制（或优化）已成为两种突出的方法。通常，机器学习方法不需要高保真模型，训练好的智能体通常能实时生成可行路径。然而，得到的路径在性能目标（如最小化路径长度或旅行时间）方面不一定最优。相比之下，最优控制和优化方法通常依赖于高保真模型，并且往往需要可能无法满足实时约束的计算量。尽管如此，这些方法更有可能产生最优或接近最优的解。为了克服每种方法的局限性并发挥各自的优势，本文提出了一种结合强化学习与弧搜索内点法的路径规划框架。数值仿真表明，所提出的方法有效地整合了强化学习的实时决策能力与弧搜索内点法的优化性能，从而改善了路径规划性能。

## Abstract
Path planning in environments containing obstacles has numerous practical applications. The problem is challenging because it is inherently nonlinear and nonconvex. Consequently, a variety of techniques have been developed to address this problem, among which machine learning and optimal control (or optimization) have emerged as two prominent approaches. In general, machine learning methods do not require a high-fidelity model, and a trained agent can often generate a feasible path in real time. However, the resulting path is not necessarily optimal with respect to performance objectives such as minimizing path length or travel time. In contrast, optimal control and optimization methods typically rely on high-fidelity models and often require computational effort that may not satisfy real-time constraints. Nevertheless, these methods are more likely to produce optimal or near-optimal solutions. To overcome the limitations of each approach while exploiting their respective strengths, this paper proposes a framework that combines reinforcement learning with an arc-search interior-point method for path planning. Numerical simulations demonstrate that the proposed approach effectively integrates the real-time decision-making capability of reinforcement learning with the optimization performance of the arc-search interior-point method, resulting in improved path-planning performance.

论文动机是结合两者的优势——利用RL的实时性快速提供一个可行初始路径，再通过优化方法精化得到最优路径，从而兼顾实时性与最优性。同时，将离线优化结果存储成数据库，实时阶段直接查表，避开在线计算瓶颈。

### 2. 论文提出的方法论

**核心思想**：  
采用深度确定性策略梯度（DDPG）训练智能体，为每个起始点生成一条可行路径（不一定最优）；再以此作为初始解，使用**弧搜索内点法（Arc-Search Interior-Point Method, ASIPM）** 求解一个非线性规划问题，得到最优路径。

**关键技术细节**：  
- **问题建模**：将路径离散为 \(f\) 段等长线段，优化变量为每段长度 \(r\) 和航向角 \(\theta_0,\dots,\theta_{f-1}\)。目标为最小化 \(r\)（等价于最小化总路径长度），约束包括终点位置等式约束、圆形障碍不等式约束（车辆不允许进入障碍半径内）、人工边界约束、航向变化限制（\(|\theta_k-\theta_{k-1}|\le 0.5\) rad）等，形成标准的含等式和不等式约束的非线性规划。  
- **弧搜索内点法（ASIPM）**：  
  - 通过引入松弛变量和拉格朗日乘子建立KKT方程组，并使用中心路径思想。  
  - 与经典内点法不同，ASIPM采用椭圆弧轨迹近似中心路径，而非直线。每一迭代需解两个线性系统：方程组(12)给出搜索方向 \(\delta v\)，方程组(13)给出弧的二阶导数 \(\Deltav\)，从而构造椭圆弧 \(v(\alpha) = v_k - \delta v \sin\alpha + \Deltav (1-\cos\alpha)\)。  
  - 通过回退线搜索保证 \(w>0, s>0, z>0, g(x)>0\)，同时满足惩罚函数下降和中心条件，最终收敛到KKT点。  
  - 算法利用Lemma III.1简化：若初始 \(w^0 = z^0\)，则后续 \(w^k = z^k\)，减少计算量。  
  - 为提升效率，将不等式分为非线性与线性两组，线性约束的二阶导数为零，可省略计算。  
- **初始可行路径生成**：优先使用DDPG生成的路径；若DDPG失败，则使用启发式规则或解析中心法生成一个严格内点（满足严格不等式）。

**算法流程（Algorithm III.1）**：  
1. 初始化满足严格可行的变量。  
2. 循环直到KKT残差小于阈值：  
   - 计算梯度、Hessian等。  
   - 选障碍参数 \(\sigma_k\)。  
   - 解(12)求 \(\delta v\)。  
   - 解(13)求 \(\Deltav\)。  
   - 计算最大步长 \(\tilde{\alpha}_k\) 保证 \(w\ge 0\)，再搜索 \(\bar{\alpha}_k\) 保证 \(g(x)>0\)，再搜索 \(\check{\alpha}_k\) 保证惩罚函数下降，再搜索 \(\hat{\alpha}_k\) 保证中心条件。  
   - 取 \(\alpha_k = \min\{\hat{\alpha}_k,\check{\alpha}_k\}\)。  
   - 更新变量 \(x, w\) 并重新设置 \(s = g(x), z = w\)。  
3. 输出最优解。

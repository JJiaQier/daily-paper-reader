## 摘要
本文引入了一种将时间行为树（TBT）解释为奖励-佩特里网（RPN）以用于强化学习（RL）的方法。为复杂的、长时域机器人任务设计奖励函数是众所周知的困难，尤其是当任务具有层次结构和时间约束时。TBT通过将时间属性纳入其叶节点，扩展了机器人应用中使用的传统行为树（BT）。这使得TBT不仅能表示由BT运算符（如顺序、回退和并行）定义的行为任务结构，还能表示任务的时间约束。在本工作中，约束使用线性时序逻辑在叶节点中指定。为了利用TBT指导RL奖励，我们提供了从TBT到佩特里网（PN）的转换，并展示了如何根据TBT结构自动分配奖励，从而得到RPN。在一系列难度递增的环境中，我们展示了基于TBT的奖励如何在普通RL失败时实现学习、提高样本效率，并提供对学习进度的灵活、直观控制。通过使用不同的奖励分配方案和TBT结构，我们展示了学习效果的影响。

## Abstract
This paper introduces an interpretation of Temporal Behavior Trees (TBTs) as Reward-Petri-Nets (RPNs) for reinforcement learning (RL). Designing reward functions for complex, long-horizon robotic tasks is notoriously difficult, especially when tasks have hierarchical structure and temporal constraints. TBTs extend conventional behavior trees (BTs) used in robotic applications by incorporating temporal properties into their leaf nodes. This allows TBTs to represents not only the behavioral task structure defined by BT operators such as Sequence, Fallback, and Parallel, but also the task's temporal constraints. In this work, the constraints are specified in the leaf nodes using Linear Temporal Logic. In order to inform RL rewards using TBTs, we provide a translation from TBT into a Petri Net (PN) and show how rewards can be automatically assigned based on the TBT's structure, resulting in a RPN. In a series of increasingly challenging environments, we demonstrate how TBT-based rewards enable learning where vanilla RL fails, improve sample efficiency, and offer flexible, intuitive control over the learning progress. We showcase the learning impact by using different reward distribution schemes and TBT structures.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：强化学习在处理复杂、长周期（long-horizon）机器人任务时，面临稀疏奖励和奖励设计困难的问题，特别是当任务具有层次结构和时间约束时，传统手工设计奖励函数极为困难，且难以保证安全性和效率。
- **背景**：已有工作尝试使用规范语言（如LTL、自动机）自动生成奖励，但往往缺乏对子任务重要性的灵活控制，且难以处理并行任务的状态爆炸问题。行为树（BT）在机器人领域广泛使用，但缺乏时间约束表达。本文结合BT和时序逻辑，提出时间行为树（TBT），并转换为奖励Petri网（RPN），实现自动化、可调控的稠密奖励生成。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：将TBT规范递归翻译为Petri网（PN），再扩展为奖励Petri网（RPN），通过TBT结构自动分配奖励，使得奖励信号与任务进度严格对齐，并允许用户通过调整分配函数控制子任务重要性。
- **关键技术细节**：
  - **TBT定义**：继承BT的Sequence、Fallback、Parallel运算符，叶节点使用线性时序逻辑（LTL）公式（如◆a、□b等）作为监控属性。
  - **RPN定义**：在Petri网基础上增加守卫谓词（guard）、动作（start/stop自动机）和奖励（每个变迁可分配实值奖励）。守卫确保确定性（tφ触发当LTL公式为true，t¬φ触发当为false）。
  - **构造方法**：递归地将每个TBT节点映射为Petri网子结构（含place、transition、token流）。例如，Leaf节点有p?φ（等待）、pφ（成功）、tφ（成功变迁）、t¬φ（失败变迁）；Sequence节点依次连接子节点；Parallel节点收集M个token后才触发等。
  - **奖励分配**：引入分配函数族（fn_Leaf, fn_Fback, fn_Par, fn_Seq），支持均匀分配、单调递增分配等。例如，fn_Seq可将总奖励r按i/n分配给各子节点，使得后续子任务奖励更高。
  - **嵌入MDP**：定义MDP-RPN，环境状态与RPN标记联合作为状态，每步根据标签函数和自动机更新标记，并累计所有触发变迁的奖励。

## 3. 实验设计
- **实验场景**：基于MiniGrid框架，构建了5个难度递增的网格世界任务：
  1. **Unlock**：移动→捡钥匙→开门。
  2. **UnlockPickup**：开门后进入第二房间→丢弃钥匙→捡起目标物体。
  3. **BlockedUnlockPickup**：增加障碍物（需先移开障碍物再开门）。
  4. **ObstructedMaze-2Dlh**：多个锁门、多个钥匙，需依次开门（无障碍物），属于hard exploration问题。
  5. **ObstructedMaze-1Q**：结合障碍物和多锁门，起始位置更远，最困难。
- **Benchmark**：使用MiniGrid默认稀疏奖励（r = 1 - 0.9^(nsteps/nmax)）作为Vanilla Baseline。
- **对比方法**：
  - **Vanilla-Baseline**：标准PPO，无TBT。
  - **TBT-Baseline**：TBT作为观测输入，仅在根节点满足时给出单位奖励（稀疏）。
  - **TBT-Uniform**：奖励均匀分配到所有TBT节点。
  - **TBT-MonInc**：奖励仅分配给叶节点，且严格单调递增（后续子目标奖励更高）。
- **算法**：PPO（Stable Baselines3实现），超参数默认，每环境5个随机种子运行。

## 6. 主要结论与发现
- TBT-generated reward（尤其是TBT-MonInc）能够使RL在Vanilla PPO完全失败的任务（如ObstructedMaze-2Dlh和-1Q）中成功学习策略。
- 基于TBT的稠密奖励显著提升样本效率，学习曲线收敛更快，方差更低。
- TBT-Baseline（稀疏）也能部分解决探索问题，但性能不如稠密方案。
- 单调递增奖励（MonInc）在复杂环境中略优于均匀分配，说明合理分配子任务重要性是有益的。
- TBT结构天然支持模块化、可重用，且可通过参数化（如颜色Fallback）轻松扩展到多目标场景。

## 7. 优点
- **方法论创新**：首次将TBT与Petri网结合用于奖励塑形，提供了一种将形式化规范转化为可解释、可调控的奖励函数框架。
- **灵活性**：用户可通过调整分配函数和TBT结构（嵌套、并行、回退）精细控制学习过程。

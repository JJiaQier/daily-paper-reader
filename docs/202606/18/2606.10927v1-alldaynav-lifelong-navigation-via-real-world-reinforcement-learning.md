## 摘要
在动态环境中进行终身具身导航要求机器人从碎片化观测中形成持久的场景理解，而现有依赖显式地图或场景图的方法在结构化环境之外难以泛化。我们提出AllDayNav，一种终身自我学习导航框架，通过强化学习将场景动态隐式编码到大型模型的十亿级参数中，并由自进化多模态记忆驱动——该记忆维护和更新视觉关键帧、语义描述及时间上下文，同时自主生成开放词汇指令、图像目标和结构化奖励。在合成环境和真实环境中的跨房间、跨回合和跨任务场景实验表明，AllDayNav的成功率接近100%，并且在路径效率和鲁棒性上持续优于基于地图、VLM和RL的强基线，证明了隐式、记忆驱动的强化学习可作为显式地图构建的可扩展替代方案，实现可靠的终身导航。

## Abstract
Lifelong embodied navigation in dynamic environments requires robots to form persistent scene understanding from fragmentary observations, which remains difficult for existing methods that rely on explicit maps or scene graphs and struggle to generalize beyond structured settings. We propose AllDayNav, a lifelong self-learning navigation framework that implicitly encodes scene dynamics into the billion-scale parameters of a large model via reinforcement learning, powered by a self-evolving multimodal memory that maintains and updates visual keyframes, semantic descriptions, and temporal context while autonomously generating open-vocabulary instructions, image goals, and structured rewards. Experiments in both synthetic and real-world environments across cross-room, cross-episode, and cross-task scenarios show that AllDayNav achieves success rates approaching $100\%$ and consistently surpasses strong map-based, VLM, and RL baselines in path efficiency and robustness, demonstrating implicit, memory-driven reinforcement learning as a scalable alternative to explicit mapping for reliable lifelong navigation.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：**记忆-策略协同进化（Memory–Policy Co-evolution）**。机器人通过一个自进化的多模态记忆数据库（M）存储视觉关键帧、语义描述和时间戳，并利用记忆生成自我指令和检索视觉目标，进而驱动基于保守Q学习（CQL）的强化学习来更新VLA策略。新策略又促进更高效的探索，使记忆更丰富，形成正反馈循环。
- **关键技术细节**：
  - **VLA导航骨干**：基于Qwen2-7B transformer，使用SigLIP和DINOv2双编码器提取语义和结构特征，通过MLP融合。观测序列包括当前帧、目标图像和经过**全局平均池化压缩的历史帧**（带指数衰减注意力掩码）。动作表示为**8个局部航点**（K=8）。
  - **自进化多模态记忆**：每次探索中，只有当新帧与最近关键帧的视觉嵌入差异大于阈值（δ_change=0.15）时才作为候选。加入记忆前与已有条目比较，若最大余弦相似度<0.7则作为**新条目**插入（由VLM生成描述）；若>0.7则用图像-文本对齐分数衡量是否替换旧条目，保证记忆多样性。
  - **自我指令生成与混合目标检索**：每隔10回合或记忆增加20%时，用VLM利用当前记忆描述生成50条多样化指令（物体、功能、空间、时序等）。检索目标时，优先从记忆用VLM语义检索；若置信度<0.6或早期探索概率退避，则回退到互联网图片集合（G_internet）。
  - **保守Q学习（CQL）**：防止Q值过估计。奖励包括终端成功奖励（+10）、进度奖励（相似度超过0.5/0.6/0.7时触发）、时间惩罚（-0.01/步）和碰撞惩罚（-0.1）。策略优化目标结合Q值最大化与行为克隆正则化（λ_bc=0.1）。
- **算法流程**（算法1）：
  1. 初始化记忆M、回放缓冲区B、Critic Q_φ。
  2. 同时运行两个并行进程：
     - **主动探索循环**：定期用记忆生成指令→混合检索目标→执行策略收集轨迹→更新M与B。
     - **策略优化循环**：当B足够时采样批次，先更新Critic（最小化L_CQL），再更新Policy（最小化L_policy）。
